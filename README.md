A modern, responsive personal portfolio website showcasing my expertise in **front-end development** and **graphic design**. Built with clean code, smooth animations, and an intuitive user experience.

## Features

- **Modern Design** - Sleek, glassmorphic UI with gradient accents and smooth animations
- **Fully Responsive** - Optimized for desktop, tablet, and mobile devices
- **Smooth Animations** - Scroll reveal effects and interactive hover states
- **Accessible** - Semantic HTML with proper ARIA labels and keyboard navigation
- **Portfolio Showcase** - Dedicated sections for projects and graphic design work
- **Skills Dashboard** - Interactive tabs showing technical and design skills with progress bars
- **Contact Section** - Easy-to-use contact form with multiple communication options
- **Social Integration** - Links to GitHub, LinkedIn, and email

## Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- No installation required - open directly in browser

### How to View
1. Open `index.html` in your web browser
2. Navigate through sections using the navbar
3. Explore projects and graphics in their respective sections
4. View responsive design by resizing your browser window

### Live Features
- **Smooth Scroll Navigation** - Click any navbar link to smoothly scroll to sections
- **Interactive Skill Bars** - Animated progress bars showing proficiency levels
- **Hover Effects** - Explore interactive hover states on project and graphic cards
- **Responsive Design** - View on any device - automatically adapts to screen size
